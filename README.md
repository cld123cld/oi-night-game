# 集训之夜 · 监控室

> 一个 OIer 做的生存小游戏。你是机房里最后一个还在改代码的人，
> 用监控撑过 23 个小时（0:00 → 23:00）。

**在线试玩**：部署后把下面的链接换成你自己的
`https://<你的用户名>.github.io/oi-night/`

---

## 玩法

你是机房里最后一个还在改代码的人。教练不会让你熬夜 —— 但你还有题没过。

用监控盯住各个角落，撑过 **23 个小时**（0:00 → 23:00）就算赢。

### 三个麻烦

| 角色 | 行为 | 怎么应对 |
|---|---|---|
| **主教练** | 走 办公室 → 走廊 → 大门 | 他到门口时**关上大门**能挡住，但门会被撞掉耐久。耐久归零就破门 |
| **副教练** | 走 后窗 → 你的身后 | **关门对他没用**。他溜到你身后时，你必须在 **7 秒内**切到刷题模式并**保持**，让他以为你在学习。**盯着摄像头吓不退他** |
| **同学** | 待在集训教室 | 你不看教室，他的**捣乱条**就涨；满了就 **JC 你**：大门被打开。盯着教室能把捣乱条压下去 |

修门必须**先开门** —— 修的时候如果主教练在门口，直接没了。

### 操作

- 右侧 **1~6 号按钮** 或键盘 `1`-`6`：切换摄像头
- `空格`：切换 监控 / 刷题
- `Q`：开关大门　`E`：维修大门

### 难度

简单 / 普通 / 困难 / 地狱 / 史诗。

## 成就系统（17 个）

| 等级 | 名称 | 解锁条件 |
|---|---|---|
| A | 摸鱼专家 | 副教练站到你身后，你拖到只剩 2 秒才去刷题 —— 还活着 |
| S | 刀尖舞者 | 主教练堵门 + 副教练在身后 + 门耐久 <10%，那一刻你还活着 |
| S | JC 神 | 一局内被同学 JC 了 5 次 |
| B | 门神 | 通关，且全程门耐久没低于 50% |
| B | 卷王 | 一局内 ≥45% 的时间在刷题 |
| B | 友好交流 | 全程没被 JC，并且通关 |
| A | 你干嘛 | 在捣乱值 ≥95% 时成功打断 |
| B | 诚实劳动 | 刷题占比 ≥ 80% |
| A | 史诗幸存者 | 史诗难度通关 |
| B | 江湖老六 | 副教练来袭前 ≥2 秒你就已经在刷题，而且之前一次都没刷过 |
| A | 闪电切换 | 7 秒内连续切换模式 3 次，且副教练已在身后 ≥5 秒 |
| A | JC 绝缘体 | 累计 10 局没被 JC 过 |
| S | 压线通关 | 通关前 10 秒内，门耐久 ≤5% 且没归零 |
| A | 捣乱大师 | 通关前 5 秒内捣乱值 ≥80%，同时门耐久 ≥50% |
| C | 不要JC我啊！！！ | 被 JC 时，大门耐久 ≥80% |
| A | JC 没用！ | 被 JC 时，大门耐久 <10% |
| A | JC 成功 | 你压制过捣乱值，可还是被 JC 了（压制时没压到 0） |

成就**永久解锁**，存在 `localStorage` 里。主界面有成就墙，没解锁的显示为暗色 `???`。

## 评分系统

```
基础分    = 撑过的小时数 × 40
通关奖励  = 1500（未通关则 0，且不吃难度倍率）
耐久奖励  = 剩余门耐久 × 2（仅通关）
JC 惩罚   = 被 JC 次数 × 80
成就加分  = 本局解锁的成就分（C=80 / B=150 / A=300 / S=500）

总分 = (基础 + 耐久 - JC惩罚 + 成就) × 难度倍率 + 通关奖励
```

难度倍率：简单 0.8 / 普通 1.0 / 困难 1.3 / 地狱 1.7 / 史诗 2.2

评级：

| 评级 | 分数线 |
|---|---|
| SSS | ≥ 4200 |
| SS | ≥ 3400 |
| S | ≥ 2700 |
| A | ≥ 1900 |
| B | ≥ 1200 |
| C | ≥ 600 |
| D | < 600 |

### 为什么这么定

**通关奖励占大头**（1500），所以"活着出去"远比"多撑几小时"重要 ——
不然赖着不死反而能刷分，不符合生存游戏的逻辑。

**通关奖励不吃难度倍率**，只让表现分吃。早期版本让通关奖励也吃倍率，
结果模拟器跑出来地狱/史诗通关清一色 SSS，评分完全失去区分度。

**评级线是用模拟器校准的**（`tools/score_sim.js`，三种玩法风格 × 5 档难度）：

```
玩法风格：optimal（最优）
难度    平均分   评级分布
简单     2395    A:99%
普通     2523    A:79% S:19%
困难     2599    S:62% A:20%
地狱     1730    S:24% SS:16% D:32%
史诗     1316    D:49% SSS:12%
```

典型局面：

| 局面 | 分数 | 评级 |
|---|---|---|
| 未通关，撑 10 小时 | 240 | D |
| 未通关，撑 22 小时 + 成就 A | 1180 | C |
| 普通通关，一般发挥 | 2650 | A |
| 普通通关，完美 | 3620 | SS |
| 简单通关，完美 | 3196 | S |
| 史诗通关，完美 | 6164 | SSS |

**未通关最高只能到 A**（要拿到 A 得撑很久且成就多）。
**简单难度上限是 S** —— 想要 SS/SSS 必须挑战更高难度。

## 存档

用 `localStorage` 自动保存，不需要账号：

- 成就永久解锁（跨局累积）
- 每个难度的最高分
- 总局数 / 通关次数 / 无 JC 局数

主界面「最佳成绩」面板下方有**清除存档**按钮。
存档损坏会自动重置，不会崩。

## 关于平衡

难度**不是拍脑袋定的**。我写了个模拟器（`tools/sim.js`），
让一个"零延迟最优玩家"每档跑 5000 局，统计胜率：

| 难度 | 模拟胜率 | 主要死因 |
|---|---|---|
| 简单 | ~95% | — |
| 普通 | ~75% | 破门 |
| 困难 | ~50% | 破门 |
| 地狱 | ~20% | 主教练进门 |
| 史诗 | ~5% | 破门 |

（模拟玩家近乎完美，真人实际胜率会明显更低。）

### 一条重要的保命规则

**主教练堵在门口时，同学 JC 不会把门打开。**

这不是偷懒。第一版没有这条时，模拟器跑出地狱档 9.7% 胜率，
诊断后发现是这样的死法：

```
副教练危机逼你去刷题 7 秒 → 期间没法关门
      → 同学 JC 开门 + 主教练正好在门口 = 必死
```

玩家什么都做不了，这是**设计缺陷**，不是难度问题。加了这条之后胜率回到 41%。

### 最敏感的旋钮

`DIFF` 里的 **`backP`**（主教练从走廊退回办公室的概率）：

```
0.30 → 地狱胜率 1%
0.50 → 地狱胜率 41%
```

想调难度优先动它。改完可以跑 `node tools/sim.js` 验证。

## 本地运行

**方式一：直接打开**

下载 `oi-night-standalone.html`，双击即可 —— CSS 和 JS 都已内联，单个文件、完全离线。

**方式二：用三个源文件**

```bash
git clone https://github.com/<你的用户名>/oi-night.git
cd oi-night
# 双击 index.html，或起个本地服务器
python3 -m http.server 8000
```

---

## 部署到 GitHub Pages

1. 在 GitHub 点右上角 **+ → New repository**
2. 仓库名填 `oi-night`，选 **Public**，勾选 **Add a README**（如果这里已经上传了就别勾）
3. 把 `index.html` / `style.css` / `script.js` 上传（可以直接在网页上拖）
4. 进仓库 → **Settings** → 左侧 **Pages**
5. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`，文件夹选 `/ (root)`
6. 点 **Save**，等一两分钟

就完事了。地址是：

```
https://<你的用户名>.github.io/oi-night/
```

以后改了代码，重新上传文件，等一两分钟就自动更新。

oi-night/
