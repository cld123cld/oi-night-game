把游戏传到 GitHub，让全世界能玩

第一次用 GitHub？没关系，跟着做就行。全程点点鼠标，不用敲命令。

先记住一件事：整个流程大约 10 分钟，不需要安装任何软件， 全程在网页上操作。你只需要一个邮箱和一个浏览器。

第 1 步 · 注册 GitHub 账号

1 打开 github.com，右上角点 Sign up（注册）
2 填邮箱 → 密码 → 用户名
邮箱：你常用的邮箱

密码：至少 15 位或 8 位含数字和字母

用户名：这个很重要！它决定你以后的网址
用户名怎么起？只能用英文字母、数字、短横线。 比如叫 zhang-san，那你的网址就是 zhang-san.github.io。
建议起个你以后也不想改的 —— 改了用户名，网址就变了。
3 会有个拼图验证，按提示转一下图片就行
4 去邮箱收验证码，填进去
⚠️ 这一步千万别跳过！没验证邮箱的话，后面 GitHub Pages 开不了， 你会卡在第 4 步不知道为什么。如果收不到邮件，看看垃圾箱。
5 后面问你"用 GitHub 做什么"，选 Just me / 随便选，不影响

第 2 步 · 新建一个仓库

1 登录之后，看页面右上角，点 "+" 号 → 选 New repository
＋ ▾ → 点开下拉菜单
New repository
2 按下面这样填：
Repository name（仓库名）：oi-night-game
↑ 必须是小写英文。这个名字就是网址的最后一段， 打开时必须一字不差

Description（描述）：选填，比如写「集训之夜 · 监控模拟小游戏」

● Public　　○ Private
↑ 必须选 Public 免费的 GitHub Pages 只对公开仓库开放

Add a README file：□ 不勾
↑ 我们已经有 README.md 了，勾了反而冲突
3 点最下面的绿色按钮 Create repository
成功的话，你会看到一个空仓库页面，中间写着 "Quick setup — if you've done this kind of thing before"。 这就对了。

第 3 步 · 上传文件

要上传哪几个？就这 5 个，都在你解压出来的 oi-night 文件夹里：
文件必须？
index.html✅ 必须，名字不能改
style.css✅ 必须
script.js✅ 必须
README.md建议传，会显示在仓库首页
LICENSE建议传，声明允许别人玩和改
oi-night-standalone.html 和 tools/ 不用传 （一个太大，一个是开发工具）。
注意：三个文件必须在根目录，不要拖进任何子文件夹。
1 在仓库页面，找到中间偏上的链接 "uploading an existing file"，点它
页面中间有一行小字：
…or uploading an existing file ← 点这个
（如果找不到：仓库页面上有个 Add file ▾ 按钮，点开选 Upload files）
2 把 5 个文件直接拖进那个虚线框里
也可以点 choose your files 手动选
可以一次选中多个文件（按住 Ctrl 点）
3 等文件传完（下面会出现 5 个小文件条目，带绿色勾）
4 滚到页面最下面，有个 Commit changes 区：
第一行：init（随便写，就是个备注）

第二行：选填，可以不写


Commit changes ← 绿色按钮，点它
成功的话，页面会跳回仓库首页，你能看到 5 个文件列在那儿， 下面还显示 README.md 的内容。

第 4 步 · 开启 GitHub Pages

1 仓库页面最上面，有一排标签： Code Issues Pull requests Actions Projects Wiki Security Insights Settings
点最右边的 Settings（⚙️ 齿轮图标那个）
找不到？就在仓库名下面那一排，最右边。
2 在左边的菜单里，往下找，点 Pages
左侧菜单：
General / Access / Collaborators / Pages / …
3 中间找到 "Build and deployment" 这一块：
Source（来源）：选 Deploy from a branch ← 默认可能就是

Branch（分支）： main ▾ 选 main　 / (root) ▾ 选 / (root)
↑ 两个都要选对！文件夹必须是 / (root)，不能是 /docs

Save ← 别忘了点保存
4 点完 Save，页面顶部会出现提示： "Your site is live at https://xxx.github.io/oi-night/"
要等 1~2 分钟才真正生效。第一次可能要等 5 分钟。
如果 Branch 那里没有 main 可选，说明你的默认分支叫 master （老版本 GitHub 的默认叫法）。选 master 就行，效果一样。

第 5 步 · 打开网址测试

你的网址是这个（把 你的用户名 换成你注册时填的）：

https://你的用户名.github.io/你的仓库名/
1 把这个网址复制到浏览器打开
2 应该能看到「集训之夜」的主界面，有难度选择和成就墙
3 点「进入监控室」试玩一下，再按 F5 刷新 —— 成就还在，说明存档正常
到这儿就成功了！把这个网址发给同学、发到洛谷/QQ群， 谁都能直接玩，不用下载。

分享小技巧

  • 发给同学单文件版：oi-night-standalone.html 才 70KB，QQ 直接传，对方下载后双击就能玩，不用联网
  • 在 README 里放链接：把你网址写进 README，别人点开仓库就能看到
  • 手机上也能玩，但屏幕小，体验不如电脑。可以提示"建议横屏"

以后怎么更新

比如你改了难度数值、加了新成就，想让线上也更新：

1 回到仓库页面，点进你要改的文件（比如 script.js）
2 右上角有个 ✏️ 铅笔图标，点它就能在线编辑
3 改完滚到底，点 Commit changes
4 等 1~2 分钟，刷新网址就是新版了
浏览器可能有缓存！如果刷新后还是旧的，按 Ctrl + F5（强制刷新），或者 Ctrl + Shift + Delete 清缓存。

想换整个文件的话：仓库页面 → 点文件 → 右上角 🗑️ 删除 → 再重新上传。

打不开 / 出问题怎么办

现象原因 & 解决办法
网址显示 404 ① 等了没够 2 分钟，再等等
② 网址里的仓库名拼错了 —— 仓库叫 oi-night-game，网址就必须是 .../oi-night-game/，少个 -game 就是 404
③ Pages 没开或 Branch 没选对
网址显示 404（第二种） ① 等了没够 2 分钟，再等等
② 仓库名拼错了 —— 网址里的仓库名必须完全一样（大小写敏感）
③ Pages 的 Branch 没选对，回去检查
页面能开但没有样式（一片白底黑字） css 文件没传上，或者不在根目录。检查仓库里有没有 style.css
游戏点不了 / 没反应 script.js 没传上。按 F12 打开控制台看红色报错
Settings 里找不到 Pages 邮箱没验证。去邮箱点验证链接，或者仓库是不是 Private 了
打不开 github.com 国内有时访问不稳定，换个时间试、换网络、或用手机热点。 也可以把 oi-night-standalone.html 直接发给别人玩（不需要 GitHub）
成就刷新后没了 正常现象只有一种：你换域名了（比如从本地 file:// 换到 github.io）。浏览器按域名隔离存储。
解决：在游戏里点「导出存档」存好，到新网址点「导入存档」

关于国内访问

GitHub 在国内有时候会比较慢，这是正常的。几个办法：

  • 多刷新几次，或换个时间段
  • 用手机热点试试
  • 备选方案：如果想让国内访问更快，可以考虑 Vercel（vercel.com）或 Netlify， 同样免费、同样支持静态页面，上传方式也差不多
  • 最省事的方案：直接发单文件版给别人，完全绕开这个问题
